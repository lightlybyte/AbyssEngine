# Contributing to DATS

Thank you for your interest in contributing to **DATS (Dynamic Arms Training Simulator)** and **Abyss Engine**.

DATS is currently in alpha development. Contributions should focus on improving stability, performance, maintainability, and compatibility with supported hardware.

## Before Contributing

- Review the project README and the [DSAL 1.0 license](LICENSE).
- Check existing issues and pull requests before starting work.
- For large changes, open an issue or discussion first to describe the proposed work.
- Keep contributions focused and avoid unrelated changes.

## What You Can Contribute

Contributions may include:

- Bug fixes and stability improvements.
- Performance optimizations, especially for low-end hardware.
- Compatibility improvements for supported operating systems and GPUs.
- Improvements to documentation.
- Asset pipeline, engine, simulation, or modding-system improvements.

New features should fit the project's goals and technical direction.

## Development Guidelines

- Follow the existing code style and project structure.
- Keep changes small, focused, and easy to review.
- Avoid introducing unnecessary dependencies.
- Do not include generated files, build artifacts, or unrelated formatting changes.
- Clearly document non-obvious behavior and complex implementation details.
- Do not claim performance improvements without measurements or reproducible evidence.

## Submitting a Contribution

1. Fork the repository and create a branch for your changes.
2. Make your changes.
3. Build and test the affected components.
4. Review your changes for unrelated edits, regressions, and formatting issues.
5. Submit a pull request describing:
   - What changed.
   - Why the change is needed.
   - How it was tested.
   - Any known limitations or compatibility considerations.

For bug fixes, include reproduction steps and relevant logs or error messages when possible.

## Reporting Bugs

When reporting a bug, provide as much of the following information as possible:

- Operating system and version.
- CPU, GPU, and available RAM.
- DATS or Abyss Engine version or commit.
- Steps to reproduce the issue.
- Expected behavior and actual behavior.
- Relevant logs, screenshots, or crash information.

Remove private information from logs before posting them.

Contributions are subject to the terms of that license. Review [LICENSE](LICENSE) before contributing.

## Questions

For questions about contributing, open a repository issue or discussion, if available.
